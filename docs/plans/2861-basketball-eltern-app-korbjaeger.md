# Plan: Basketball-Eltern-App (Korbjäger)

Spec: [docs/specs/2861-basketball-eltern-app-korbjaeger.md](../specs/2861-basketball-eltern-app-korbjaeger.md). Issue: [#2861](https://github.com/WolfSoko/wol-sok-mono/issues/2861).

The work follows the sub-issues of #2861, one PR each, merged through its own merge request, in the order their "Blocked by" sections set; on 2026-11-08 the owner moved #2875 (deploy) to right after #2868. Every task is test first and ends in one commit. Before every commit: `npx nx format:write`, `npx nx affected -t lint,lint-templates,test,typecheck-specs`. The Firebase project id lives in `.firebaserc` only (the web config's copy is checked against it); the domain lives in the app's `SITE_URL` and, since infra cannot import an app, once more in `korbjaeger-cdk`, whose spec keeps the two equal.
